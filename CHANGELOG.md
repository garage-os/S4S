# S4S by GarageOS — Changelog

All notable changes, improvements and fixes to S4S by GarageOS will be documented here.

## [9.1.6] — Current Development Baseline

### Automotive Tools Marketplace
- Added dedicated professional tools marketplace.
- Introduced four automotive equipment categories.
- Added Tools Provider application and approval workflows.
- Added provider subscription management.
- Introduced Excel bulk product import.
- Added product galleries and image previews.
- Added provider dashboard and offer management.
- Added marketplace engagement statistics.
- Introduced collapsible provider navigation.

### Automotive Parts Marketplace
- Improved marketplace scrolling performance.
- Improved product image loading.
- Optimized product search and filtering.
- Improved product preview behavior.
- Reduced unnecessary background requests.

### Connection & Reliability
- Improved automotive catalog connection stability.
- Improved session management.
- Improved inactivity detection.
- Improved connection cleanup.
- Improved handling of temporary network interruptions.
- Improved service maintenance behavior.

### User Interface
- Improved navigation icons and layout.
- Improved marketplace card design.
- Improved provider workspace organization.
- Improved English and Egyptian Arabic presentation.
- Continued dark and light theme improvements.

### Community & Documentation
- Established the official GarageOS GitHub organization.
- Published the official S4S product repository.
- Added application screenshots and product documentation.
- Introduced GitHub Discussions.
- Added Bug Report, Feature Request and Technical Support templates.

### Known Limitations
- Windows installer code signing remains pending.
- Further marketplace regression testing is required.
- Notification delivery requires additional verification.
- Accessibility and localization improvements remain ongoing.
