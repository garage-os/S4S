Use our structured issue templates:

- [Bug Report](https://github.com/garage-os/S4S/issues/new/choose)
- [Feature Request](https://github.com/garage-os/S4S/issues/new/choose)

Please provide your application version, Windows version, affected module and any relevant error messages.

## Basic Troubleshooting

Before submitting a support request:

1. Check your internet connection.
2. Restart the S4S application.
3. Check for available application updates.
4. Run the built-in connection diagnostics, where available.
5. Record any displayed error messages.
6. Check existing GitHub issues for similar problems.

## Privacy and Security

Never publish sensitive information in public support requests, including:

- Passwords and account credentials.
- Activation codes and access tokens.
- Customer information.
- Vehicle identification numbers (VINs).
- Private diagnostic files.
- Confidential business information.

For security vulnerabilities, please follow our [Security Policy](./SECURITY.md).
