# Security Policy

## Our Commitment

GarageOS is committed to protecting the security, privacy and integrity of S4S and its users.

Security is an essential part of our software development, infrastructure management and application release processes.

## Supported Versions

Security maintenance focuses on the latest officially supported S4S version.

Users are encouraged to install verified updates through official GarageOS distribution channels.

## Reporting a Vulnerability

If you discover a potential security vulnerability in S4S by GarageOS, please report it responsibly.

Do not disclose security vulnerabilities through public GitHub Issues, Discussions or social media.

Contact GarageOS privately through our official website:

https://garageos.pro

## Information to Include

Please provide:

- A description of the vulnerability.
- The affected application version.
- The affected feature or component.
- Steps to reproduce the vulnerability.
- Potential security impact.
- Relevant screenshots or sanitized technical evidence.

Never include passwords, access tokens, customer records, vehicle VINs or other confidential information.

## Responsible Disclosure

We ask security researchers to:

- Respect user privacy and confidentiality.
- Avoid accessing or modifying unauthorized data.
- Avoid disrupting production services.
- Avoid testing against customer accounts without permission.
- Allow reasonable time for investigation and remediation.
- Coordinate disclosure with GarageOS.

## Security Practices

Our development priorities include:

- Secure authentication and authorization.
- Encrypted network communication.
- Account and subscription access controls.
- Secure application update processes.
- Dependency monitoring.
- Secure handling of sensitive information.
- Continuous software maintenance.
- Trusted Windows installer code signing.

These are ongoing engineering priorities and do not represent an independent security certification.

## Official Distribution

Only download S4S through verified GarageOS distribution channels.

- Official website: https://garageos.pro
- Official repository: https://github.com/garage-os/S4S
- Official releases: https://github.com/garage-os/S4S/releases

## Scope

This policy applies to S4S by GarageOS.

Third-party automotive software, catalogs and external services are subject to their respective providers' security policies.
